# 블로그 디자인 리디자인 계획

## 참조 디자인 분석 (GARAGE - digital.tattooprojects.com)

### 핵심 디자인 언어
- **에디토리얼 매거진** 스타일 — 텍스트와 이미지가 지면처럼 배치됨
- **극도로 큰 타이포그래피** — 로고가 페이지 전체를 압도
- **올캡스(All Caps)** — 헤딩, 제목, 네비게이션 모두 대문자
- **이미지 우선** — 카드에서 이미지가 90%, 텍스트는 제목만
- **무경계** — 카드에 border/shadow 없음, 순수 이미지+텍스트
- **여백의 미** — 요소 간 넉넉한 여백으로 호흡감 확보
- **흑백 기조** — 순수 흰색 배경, 순수 검정 텍스트, 포인트 컬러 없음

### 현재 vs 목표 비교

| 항목 | 현재 | 목표 |
|------|------|------|
| 헤더 | sticky 바, 좌측 로고 | 중앙 대형 로고 + 우측 세로 네비 |
| 포스트 카드 | border box, 뱃지+태그 | 이미지 전체 + 하단 제목만 |
| 그리드 | 단순 1열 리스트 | 3열 에디토리얼 그리드 (크기 다양) |
| 색상 | 파란색 포인트 | 흑백 |
| 타이포 | 일반 sans-serif | 굵고 큰 display 폰트 |
| 섹션 레이블 | h2 태그 | `/ SECTION NAME` 형식 |

## 변경 범위

### Phase 1 — 데이터 레이어 (frontmatter 확장)
포스트 카드에 이미지를 표시하려면 thumbnail 필드가 필요.

**변경 파일**: `src/lib/mdx.ts`, `src/types/index.ts`

- `Post.frontmatter`에 `thumbnail?: string` 필드 추가
- thumbnail 없을 때 카테고리별 기본 색상 그라디언트로 폴백

### Phase 2 — 헤더 리디자인
**변경 파일**: `src/components/layout/Header.tsx`

```
현재:
[📈 나의 투자일지]     [홈 블로그 소개] [검색 테마]

목표:
                우상단: 홈
                       블로그
      투자일지          소개
    (대형 중앙)
```

- 헤더를 `static` (sticky 해제) — 로고가 페이지 상단에 드라마틱하게 위치
- 로고: 중앙 배치, 매우 큰 폰트 (6xl~8xl), 굵게
- 네비: 우측 상단 세로 정렬, 올캡스, 소형 텍스트
- 검색/테마 토글: 우측 하단 또는 네비 하단

### Phase 3 — 포스트 카드 리디자인
**변경 파일**: `src/components/blog/PostCard.tsx`

- border, shadow, 배경색 완전 제거
- 이미지 영역: 16:9 또는 4:3 비율, 이미지 꽉 채움
- 이미지 없으면 카테고리별 색상 그라디언트 플레이스홀더
- 제목: 이미지 하단에 올캡스, 작은 폰트, 자간 넓게
- 날짜/카테고리: 제목 위에 아주 작은 텍스트로 (선택)
- 태그 뱃지 제거

### Phase 4 — 그리드 레이아웃 리디자인
**변경 파일**: `src/components/blog/PostList.tsx`, `src/app/blog/page.tsx`

```
3열 에디토리얼 그리드:
[소] [대 - 2배 높이] [소]
[소] [소]            [소]
```

- CSS Grid 활용
- 첫 번째 포스트 또는 특정 포스트를 large card로 강조
- 섹션 레이블: `/ 최신 글` + `(모든 글 보기)` 우측 정렬

### Phase 5 — 홈페이지 리디자인
**변경 파일**: `src/app/page.tsx`

- 히어로 섹션 제거 (로고 자체가 히어로)
- Featured Posts 섹션 스타일 적용
- 카테고리 사이드바 → 하단 카테고리 필터 탭으로 변경

### Phase 6 — 타이포그래피 & 글로벌 스타일
**변경 파일**: `src/app/globals.css`, `src/app/layout.tsx`

- Google Fonts에서 display 폰트 추가 (예: `Bebas Neue` 또는 `Anton` - 무료 올캡스 폰트)
- 또는 기존 Geist 폰트를 900 weight으로 극대화
- 색상 팔레트: 순수 흑백 (`#000000`, `#ffffff`)

## 기술 고려사항

### 이미지 처리
현재 포스트에 thumbnail 이미지가 없으므로:
1. frontmatter에 `thumbnail` 필드 추가 (선택적)
2. thumbnail 없을 때 → 카테고리명 기반 CSS 그라디언트 플레이스홀더
3. Next.js `next/image` 컴포넌트로 최적화

```yaml
# frontmatter 예시
thumbnail: "/images/posts/march-week4.jpg"
```

### 반응형
- 모바일: 1열 → 2열 전환
- 태블릿: 2열
- 데스크탑: 3열 에디토리얼

### 다크모드
- 현재 다크모드 지원 유지 (배경 #0a0a0a, 텍스트 #ededed)
- 에디토리얼 스타일도 다크에서 잘 작동함

## 결정이 필요한 사항

1. **사이트 이름 표기**: 로고를 한글 "투자일지"로 할지, 영문으로 만들지?
2. **포스트 이미지**: 기존 포스트에 thumbnail을 직접 추가할지, 플레이스홀더로 갈지?
3. **카테고리 필터**: 홈/블로그 페이지에 카테고리 필터 유지 여부?
4. **헤더 sticky**: 스크롤 시 헤더 고정 여부? (참조 사이트는 고정 없음)
5. **다크모드**: 다크모드 토글 유지 여부? (참조 사이트는 라이트모드만)
